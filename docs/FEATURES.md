# 功能介绍

WeChatAgent 不是单一聊天机器人，而是一套围绕微信群记忆、观察、回复和技能扩展的控制系统。

## 1. 浏览器微信

- 通过 `wechat-selkies` 在浏览器中运行 Linux 微信。
- 默认访问 `3000` 端口。
- 支持控制台自动切换群、粘贴文本、发送文本、发送图片。
- 不直接写微信数据库，发送动作走微信窗口自动化，风险更低、可观察性更好。

## 2. 聊天同步与记忆库

- 只读读取微信本地数据库。
- 增量解密并同步消息到 `runtime/memory/wechat_memory.sqlite`。
- 支持群、成员、消息、引用、图片、表情、公众号标题、媒体索引。
- 运行状态可在控制台查看。

## 3. AI 长期记忆

- 消息级索引与检索。
- 长期事实库。
- 群摘要。
- 人物画像。
- 关系图谱。
- 事实审查与手动修正。
- 支持按群维护，不同群的数据不会混在一起使用。

## 4. 自动回复

- 基于评分阈值判断是否接话。
- 明确 `@机器人` 必回。
- 可配置安静、正常、活跃、发疯模式。
- 自动定位目标群，当前已在目标群时不重复搜索。
- 支持随机切群延迟和发送延迟。
- 忽略机器人自己的消息，避免自我循环回复。
- 总览页面显示实时状态：思考中、技能执行、发送成功、失败原因。

## 5. 技能系统

- 独立“技能”页面。
- 支持导入 `SKILL.md`、文件夹、zip、OpenAPI/HTTP 技能。
- 技能默认禁用，需手动启用。
- 权限按能力拆分：读消息、联网、LLM、发文字、发图片、脚本执行。
- 有运行日志、测试入口、配置面板、导入导出能力。

## 6. 内置技能

### 网络搜索

- 使用 Tavily 搜索网络信息。
- 可配置 API Key。
- 有额度时优先搜索，没有额度或未配置时可回退到模型能力。
- 适合赛程、新闻、实时资讯、网页信息查询。

### 斗图发图

- 使用表情包 API 获取图片。
- 触发后只发送图片，不再追加文字。
- 支持配置触发概率。
- 避免严肃、隐私、工作事故、争吵等场景斗图。

### 图片理解

- 支持 OpenAI-compatible 视觉模型。
- 可单独配置模型、拉取模型列表、测试通断。
- 支持群图片自动解析入库。
- 支持失败重试。
- 输出更偏向真实内容理解和 OCR，而不是机械描述“这是一张截图”。

### 公众号标题识别

- 保留卡片标题、来源、URL 等元信息。
- 当前不再假装读取公众号正文；无法真实读到正文时不会编造。

## 7. 群日报与图片总结

- 支持“今天”“昨天”“近 N 小时”等时间范围。
- 基于真实聊天记录生成总结。
- 支持生成图片日报并发送到微信群。
- 包含一句话总结、主要话题、干货总结、活跃成员、水王榜、代表片段。

## 8. 图片记忆库

- 按群展示照片库画廊。
- 自动解析图片并打标签。
- 显示成功、失败、等待解析统计。
- 支持点击查看图片和解析内容。
- 支持重新解析失败图片。
- 支持按群导入导出。

## 9. 数据导入导出

- 可查看数据库类型、内容容量、总容量。
- 支持按群导出。
- 支持全量、单项、多项导出。
- 支持导入备份。
- 运行级备份通过 `scripts/backup.sh` 完成。

## 10. 总览宇宙

- 展示群记忆宇宙、核心节点、事件记忆、成员排行。
- 支持排行榜前三名特殊视觉层级。
- 支持全屏查看宇宙图。
- 顶部状态区展示消息索引、会话数、模型状态、服务运行情况和自动回复实时状态。

## 11. 模型配置

- 控制台有模型页面。
- 支持多模型 Profile。
- 技能可使用主模型，也可单独配置模型。
- 模型密钥只存放在本机 `runtime/`，不会进入 GitHub 或 Docker 镜像。

## 12. 部署与维护

- GitHub 保存源码、Compose、脚本、教程。
- DockerHub 保存项目服务镜像。
- 微信登录数据、数据库 key、记忆库和模型密钥只留在部署机器。
- 支持 Docker Compose 一套服务启动。
- 支持备份和恢复。
